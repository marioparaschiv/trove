- `src/switcher.ts`: `SuggestModal` subclass. On open: `connect({ binary })` from `@trove/client` (starts the service), then `POST /prewarm`; also `GET /sources` and show a `Notice` if the vault isn't a registered source (otherwise Trove results silently never appear). `getSuggestions`: fuzzy filename matches via `prepareFuzzySearch` over `vault.getMarkdownFiles()` paths without extension (recent files via `workspace.getLastOpenFiles()` on empty query), plus cached Trove results when their query equals the current trimmed query; otherwise start a debounced (`debounce(..., ms, true)`) `POST /search` and, when it returns for the still-current query, cache it and `inputEl.dispatchEvent(new Event("input"))` to re-render.
